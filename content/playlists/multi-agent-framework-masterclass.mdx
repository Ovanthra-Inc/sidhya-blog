# Building a Multi-Agent AI Framework Masterclass

Welcome to the **Multi-Agent AI Framework Masterclass**!

This 5-part continuous series guides software engineers step-by-step through designing, building, and hardening a production-grade multi-agent AI framework from scratch in TypeScript.

### What You Will Learn Across the 5 Parts:

1. **Core Event Loop & State Machine**: Building a deterministic, step-counted state machine runtime loop with typed tool contracts.
2. **Hybrid Memory & Context Pruning**: Implementing short-term sliding windows, vector episodic memory (LanceDB), and automatic token pruning.
3. **Multi-Agent Teams & Orchestration**: Designing Supervisor lead routing, parallel worker fan-out, and explicit agent handoffs.
4. **Model Context Protocol (MCP) Integration**: Connecting your agent framework to Anthropic's Model Context Protocol for standard JSON-RPC tool discovery and streaming.
5. **Production Evals, Retries & Telemetry**: Hardening execution with exponential backoff, LLM-as-a-Judge quality assertions, and OpenTelemetry tracing.
