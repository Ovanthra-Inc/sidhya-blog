# Autonomous AI DevOps & Infrastructure Agents Masterclass

Welcome to the **Autonomous AI DevOps & Infrastructure Agents Masterclass**.

This 7-part engineering series covers designing, deploying, and securing autonomous AI agents that monitor, triage, and remediate cloud-native infrastructure in production.

### What You Will Learn Across the 7 Modules:

1. **Agentic Control Plane Architecture**: Building stateful, event-driven DevOps agent loops with LangGraph, Pydantic AI, and deterministic execution wrappers.
2. **Kubernetes Self-Healing Agents**: Automated pod crash triage (`OOMKilled`, `CrashLoopBackOff`), eBPF log inspection, and dynamic patch execution.
3. **CI/CD Pipeline Triage & Flaky Test Quarantine**: AI-driven stack trace parsing, isolated container re-runs, and auto-generated GitHub Pull Requests.
4. **GitOps Remediation & IaC Drift Correction**: Automated Terraform/Pulumi state drift detection, Human-in-the-Loop approval workflows, and ArgoCD synchronization.
5. **eBPF Kernel Observability**: Integrating Cilium kernel telemetry with LLM anomaly detection to catch silent packet drops and CPU throttling.
6. **FinOps AI Agents & GPU Cluster Optimization**: Dynamic right-sizing of LLM inference nodes, vLLM spot instance migration, and cloud cost management.
7. **Production Guardrails & Telemetry Evals**: Implementing strict RBAC gates, deterministic fallback breakers, and automated LLM-as-a-Judge evaluations.
