# AI Agent & LLM Frameworks Masterclass

Welcome to the **AI Agent & LLM Frameworks Masterclass Playlist** on Sidhya Blog.

Selecting the right framework is one of the most critical architectural decisions when building production AI software. This playlist provides complete, runnable starter guides, architectural tradeoffs, folder structures, and decision matrices for the industry's top 12 AI engineering frameworks across TypeScript and Python.

### Frameworks Covered:
1. **Mastra**: The TypeScript-First Agent & Graph Workflow Engine.
2. **Vercel AI SDK 4.0**: Edge Streaming, React 19 Generative UI & Unified Adapters.
3. **ModelFusion**: The Vendor-Neutral TypeScript Multimodal AI Library.
4. **LangGraph**: Stateful Cyclical Graph Orchestration & Checkpointing.
5. **CrewAI**: Role-Based Autonomous Agent Swarms & Task Delegation.
6. **Microsoft AutoGen (0.4+)**: Asynchronous Actor Model & Group Chats.
7. **LangChain (v0.3+)**: Declarative LCEL Runnables & Retrieval Composability.
8. **Pydantic AI**: Production Type-Safe Python Agents & Dependency Injection.
9. **Anthropic Model Context Protocol (MCP)**: Universal JSON-RPC Tool Server Standard.
10. **Microsoft Semantic Kernel**: Enterprise .NET and Python Native Hubs & Plugins.
11. **LlamaIndex**: Data Ingestion, Hierarchical Node Indices & Query Engines.
12. **Haystack 2.0**: Component-Based Modular NLP & Search Pipeline DAGs.
