# Understanding Retrieval-Augmented Generation (RAG)

Retrieval-Augmented Generation (RAG) grounds Large Language Models on external domain knowledge.

---

## 1. The RAG Architecture Flow

```flowchart
[User Query] ──> [Vector Embedding Engine] ──> [Vector Search DB]
                                                        │
                                                        ▼
[Final Answer] <── [LLM Generation Prompt] <── [Retrieved Chunks]
```

---

## 2. Python Hybrid Search Implementation

```python
from qdrant_client import QdrantClient

client = QdrantClient(host="localhost", port=6333)

def search_documents(query_text: str, top_k: int = 5):
    query_vector = embed_text(query_text)
    results = client.search(
        collection_name="tech_knowledge",
        query_vector=query_vector,
        limit=top_k
    )
    return [hit.payload for hit in results]
```
