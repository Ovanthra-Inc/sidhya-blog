# Advanced Prompt Engineering: Chain-of-Thought, ReAct, and Structured Output

Prompt engineering has evolved from trial-and-error text tweaking into a disciplined discipline for controlling language model execution behavior.

---

## 1. The ReAct (Reasoning + Acting) Prompt Pattern

```flowchart
[Input Question] ──> [Thought: Reason about requirements]
                            │
                            ▼
                    [Action: Pick Tool & Parameters]
                            │
                            ▼
                    [Observation: Tool Output]
                            │
                            ▼
                  [Final Answer / Response]
```

---

## 2. Enforcing Deterministic JSON Output

```typescript
const prompt = `
Extract key entities from the input text. Return ONLY a valid JSON object.
Do NOT include Markdown backticks or commentary.

JSON Schema:
{
  "name": string,
  "confidence": number,
  "tags": string[]
}

Input Text: "Asutosh Sidhya is an AI engineer specializing in Next.js and LangGraph."
`;
```
